## 成績怎麼算

- **實作作業 45%**：七次實作測驗各 100 分，**取最佳 5 次**平均（可以放掉兩份）。每次測驗 9–11 題，只出該作業「核心段落」的題目，作答 1 次；答錯可看提示再試（每次扣 1/3），正確答案於測驗關閉後才顯示。題目包含筆記本輸出的確定數值（token 數、參數量、資料筆數、相似度、注意力權重……）與觀察結果的概念題，多數題目要執行過筆記本才答得出來。
- **作業互評 5%**：只有 HW2 有。把第 3 節的觀察寫成**一頁**「檢索失敗案例分析」PDF，上傳到 iLearn 同儕互評活動；10/26–11/01 每人匿名評閱 3 位同學的作品（規準見 [hw2-peer-review.md](hw2-peer-review.md)）。成績＝繳交評分 80% ＋ 評量評分 20%，系統自動計算。
- **寬限**：截止後 7 天內仍可上傳與作答且不扣分；之後不受理（HW7 寬限只到 12/28，因為 12/29 是課程考核截止日）。互評活動沒有寬限。

## 難度與時間

每份作業分「核心段落」與「選做」：只有核心段落會出題，核心段落約 1.5–2 小時；選做段落給想深入的同學，不計分。

| 作業 | 性質 | 核心段落 | 說明 |
|------|------|----------|------|
| HW1、HW2、HW4、HW7 | 操作型 | 約 1.5–2 小時 | 執行、觀察、比較，需要的是耐心與細心 |
| HW3、HW5、HW6 | 原理型 | 約 2 小時 | 矩陣、注意力、損失、LoRA 等概念較抽象；先看完對應單元的影片與學習指引再做 |

七次取最佳 5 次：原理型作業卡住時可以放掉，不影響成績上限；但建議至少做完一份原理型作業，後面的單元會用到這些概念。

## 怎麼做

1. 在 GitHub 打開筆記本，按「Open in Colab」（或在 Colab 選「GitHub」分頁貼上網址）。
2. Colab 選單「執行階段 → 變更執行階段類型 → T4 GPU」。
3. 依序執行每一格；遇到「✍️ 請回答」的文字格，把你的觀察寫進去。
4. 全部跑完後「檔案 → 下載 → 下載 .ipynb」，到 iLearn 對應的「作業」上傳（檔名 `hwN_學號.ipynb`），勾選繳交聲明。
5. 上傳後「實作測驗」自動開放。

## 共同規定

- **不要更改**模型名稱與版本、隨機種子、資料檔與設定值，否則測驗的數值題會對不上。可以自己加格子做額外實驗。
- 用到的模型與資料都是公開、免申請的：`Qwen/Qwen2.5-1.5B-Instruct`（HW1、2、7）、GPT-2 124M（HW3、5、6）、Qwen3-0.6B base／reasoning（HW4）、`intfloat/multilingual-e5-small`（HW2）、UCI SMS Spam（HW6）、MATH-500（HW4）。
- 每份筆記本最後一格是「AI 使用聲明」，請務必填寫；未填以未繳交論（HW2 一頁分析是例外：缺聲明只扣 R1）。
- 可以互相討論做法，但筆記本、作答與互評都必須是自己的。教師會用程式檢查所有上傳筆記本的結構（有無輸出、版本資訊、AI 聲明），並隨機抽查內容：空白、未執行、輸出與版本不符或明顯非本人執行者，該次作業以 0 分計，重複違規依本校學則處理。
- Colab 免費額度用完或排不到 GPU 時：換個時段再試（清晨與深夜較容易）；HW1、2、7 提供 0.5B 模型切換；HW3 全部可在 CPU 執行；HW5、HW6 的訓練可把 `NUM_EPOCHS` 調小先跑完流程（測驗的數值題不依賴訓練結果）。連線中斷時重新執行即可；已下載的檔案會先驗證 SHA-256，不符時自動刪除並重新下載一次。

## 為什麼是這七個

| | 你會親手看到 | 對應的課堂概念 |
|--|--|--|
| HW1 | 文字怎麼被切成 token、下一個 token 的機率、temperature、對話模板實際送了什麼 | U1 文字接龍、U2 提示工程 |
| HW2 | 文件變向量、相似度檢索、檢索失敗的樣子、有／無檢索的差距、用模型當評審 | U3 RAG、U6 評量 |
| HW3 | 內積怎麼變成注意力權重、因果遮罩、多頭注意力、把 GPT-2 組起來數參數 | U4 Transformer、U5 內部 |
| HW4 | 用自己實作的 Qwen3 生成、自動驗證數學答案、MATH-500 正確率、多次抽樣投票、推理模型的 `<think>` | U3 深度思考、U6 評量、U10 測試時運算 |
| HW5 | 損失從 ln(50257) 一路下降、過度擬合、temperature／top-k、載入 GPT-2 權重後判若兩人 | U7 機器學習、U8 訓練、U9 預訓練 |
| HW6 | 用預訓練模型做分類微調、LoRA 省下 98% 參數、微調後接龍能力改變 | U9、U10 後訓練與遺忘 |
| HW7 | 提示注入怎麼讓評分助教給滿分、三種防禦各擋得住什麼、攻擊成功率怎麼算 | U11 安全性、U6 評量 |

HW3、HW5、HW6 的程式取自 Sebastian Raschka《Build a Large Language Model (From Scratch)》的開源套件 `llms-from-scratch`，HW4 取自《Build a Reasoning Model (From Scratch)》的 `reasoning-from-scratch`，皆為 Apache-2.0 授權；筆記本中的講解與問題為本課程改寫。想深入的同學強烈推薦直接讀這兩本書與 repo：<https://github.com/rasbt/LLMs-from-scratch>、<https://github.com/rasbt/reasoning-from-scratch>。
