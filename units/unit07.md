## 重點提示（Highlights）

- **機器學習 = 根據資料找出函式 f**。本單元的 f 是「迴歸」：輸入投影片頁數等特徵，輸出一個數字（上課時長）。
- **三步驟 + 1**：① 我要找什麼（定義 loss）② 我有哪些選擇（候選函式集合 = 模型，出自 domain knowledge）③ 選一個最好的（loss 最低 = optimization）＋ 檢驗它是不是我要的（驗證／測試）。
- **Loss**：MSE = 預測與實際差的平方取平均，越小越好；這和第 6 單元的評量過程其實一樣。
- **特徵只能是數字**（有沒有 “Learning” → 0/1）；**參數**（w1、b）由資料學出來，**超參數**（learning rate、batch size、epoch 數、神經元數 H）由人設定。
- **梯度下降**：算斜率（套件自動算）→ 斜率負往右、斜率正往左 → 步伐 = learning rate × 斜率；在適當的步長與平滑條件下，只能保證收斂到梯度接近 0 的（近似）stationary point——可能是 local minimum，也可能是 saddle point 或小梯度區；不保證 global minimum，步長不當還可能震盪或發散。線性迴歸 + MSE 其實有公式解，但一般模型沒有。
- **Learning rate**：太小慢到懷疑人生、太大跨過頭；「概念很簡單，做起來不容易」。
- **Batch / epoch / shuffle**：資料多時「迫不及待更新參數」；1 epoch = 看完所有 batch，N/B 次更新；batch size = 1 是 SGD、= 全部是 full batch；每個 epoch 重新 shuffle。
- **訓練／驗證／測試**：驗證 = 模擬考，測試 = 真的大考、只有一次；驗證資料若一再被用來選模型、調超參數，選出來的模型會「適應」驗證資料（adaptive selection bias），驗證分數失去意義——老師的說法是「驗證資料用無限次就等於亂給答案」，這也是公開 benchmark 上的高分不一定反映真實能力的原因之一；測試資料要與選模流程隔離。
- **目標不一致**：2021 年資料訓練、2025 年課程驗證 loss 很差 → 訓練資料要貼近實際情境。
- **選擇太少 → 非線性**：有限區間上的連續曲線 ≈ 夠多段的 piecewise linear，而 piecewise linear = 常數 + 一組 ReLU 的加總（投影片簡寫成「Any Curves ≈ Piecewise Linear」）；每個 ReLU 是神經元 → hidden layer → 神經網路 → 多層 = 深度學習；backpropagation 有效率地算梯度。
- **選擇太多 → overfitting**：加特徵後訓練 loss 22、驗證 loss 1307；f_lazy 把訓練資料背下來訓練 loss 0 驗證炸裂；「看著貼紙開車，只在駕訓班能開」。對策：每個 epoch 量驗證 loss、劃定不大不小的範圍。

## 實例（Worked example）

老師預測「什麼時候下課」的完整迭代（數字取自投影片）：

| 迭代 | 做了什麼 | 訓練 loss | 驗證 loss | 診斷 |
|---|---|---|---|---|
| 1 | 線性模型 y = w1·x1 + b，用 2021 年資料訓練 | 240 | 1143（2025 年課程） | 目標不一致：老師講課節奏變了 → 換訓練資料 |
| 2 | 改用 2024 年資料訓練 | 71 | 122 | 還不夠好，可能是「選擇太少」 |
| 3 | 改成 100 個 ReLU 的神經網路 | 80 | – | 比線性還差 → optimization 出問題（只能看 loss curve） |
| 4 | 暴調 learning rate、epoch、batch size | 41 | – | 最佳化終於成功 |
| 5 | 再加特徵（總字數、每頁平均字數） | 22 | 1307 | 訓練變好、驗證炸裂 → overfitting，選擇太多 |

同一個問題，三步驟每一步都可能出錯：loss 定義不對目標、模型範圍太小或太大、最佳化失敗。判斷「是哪一種」要同時看訓練與驗證 loss。

## 延伸思考（選做，不計分、不需繳交）

選一個你生活中想預測的數字（例如通勤時間、校門口飲料店排隊分鐘數、某科期末成績、一篇貼文的按讚數）。請依三步驟寫出：

1. **輸出 y 是什麼**；**特徵 x 有哪些**（必須是數字，或說明怎麼編成數字）；
2. **loss 怎麼定義**（用 MSE 合理嗎？答錯 10 分鐘和答錯 1 小時對你來說懲罰一樣嗎？）；
