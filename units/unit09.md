## 重點提示（Highlights）

- **三階段**：預訓練（學齡前，熟悉人類語言，自督導）→ SFT（上學校，人類提供標準答案）→ RLHF（出社會，人類僅提供回饋）；後兩者合稱 **alignment**（學「應該如何回應」）。
- **每個階段都沿用同一個「文字接龍」模型**：架構與輸出空間（下一個 token 的分類，類別數 = 詞彙表大小）相同，每階段以前一階段的參數為初始化；老師說「三步驟相同、只有教材不同」是就模型與輸出而言。實際上三階段的**資料、目標函數與最佳化方式**不同：預訓練與 SFT 對老師給的文字逐 token 最小化 cross entropy，RLHF 則對模型自己產生的完整回答用 reward 做 policy optimization（PPO 類）或用偏好對做分類式損失（DPO）；用 LoRA 等 PEFT 時也不一定更新全部參數。
- **自督導式學習**：任何文字都能拆成「人工智 → 慧」的題目，人工介入極少，資料要多少有多少（今日約 15T token 等級）；學語言知識較容易，世界知識無窮無盡。
- **資料越多越好嗎？** 算力固定下要在「大模型小資料」與「小模型大資料」間取捨（Chinchilla）；品質也重要（去重、過濾、用 LLM 改寫）。
- **預訓練模型是璞玉**：網路資料沒教它「問題 → 回答」，所以常不回答；但它往往已有正確答案，SFT／RL 讓它更傾向選對。
- **SFT 主要不是用來給新知識**（投影片標題：「SFT 並不是給語言模型新的知識」）：知識主要來自預訓練，且同一知識要「從不同角度反覆講」（MyGO 實驗 0% → 96%）；SFT 教的是回答方式。研究（Gekhman et al., 2024）顯示用 SFT 硬教模型原本不會的事實並非不可能，但學得明顯較慢、且學會後幻覺傾向上升；用 **MaybeKnown** 的問題最有幫助。
- **Alignment 沒有本質變化**：對齊前後大多數 token 的分佈不變（Unlocking Spell）；預訓練留下的遺跡持續影響行為（Embers of Autoregression）。
- **兩條路線**：一堆專才（BERT 系列）vs 一個通才（FLAN，上千任務）。**SFT 是畫龍點睛**：LIMA 1k 筆即可，位置要點對（選長的、弱智吧）；**知識蒸餾**：用已對齊模型的輸出訓練自己的模型（Alpaca：用 text-davinci-003 產生 52k 筆指令資料，微調運算約 100 美元、資料生成另約 500 美元以下；Vicuna：用 ShareGPT 上使用者分享的 ChatGPT 對話約 70k 筆，微調約 140 美元）。
- **SFT vs RLHF**：前者逐 token 算 loss（只問過程不問結果，資料是老師給的），後者對整個回答給 reward（只問結果不問過程，資料是模型自己產生的），能「因材施教」。
- **RL 的困難與解法**：人已離開、reward 不可微 → PPO 這類 policy-gradient 方法「拉近好回答、拉遠壞回答」，並用 **reward model** 代替人打分（批評比生成容易）；RLAIF 用 AI 當評審。投影片一併列出的 DPO 走另一條路：直接用「A 比 B 好」的偏好對做分類式損失，不需要顯式 reward model，也不做 policy gradient 的抽樣更新。

## 實例（Worked example）

用「臺灣最高的山是哪座？」走完三個階段：

1. **預訓練後**：模型只是接龍。可能接「玉山」，也可能接「誰來告訴我呀？」或「(A) 雪山 (B) 阿里山……」——因為網路上這種句子後面什麼都有。
2. **SFT**：人類寫一筆「User：臺灣最高的山是哪座？ AI：玉山」。訓練時拆成三題接龍：「…AI:」→「玉」（l₁）、「…AI:玉」→「山」（l₂）、「…AI:玉山」→「[END]」（l₃），L = l₁ + l₂ + l₃。注意：SFT 主要是教它「用這種格式回答」，「玉山」這個知識是預訓練學來的。
3. **RLHF**：模型自己產生兩個回答「玉山」與「我不知道」，人只說前者好（r = +1）、後者差（r = −1）。PPO 這類 policy-gradient 方法把「玉」「山」的機率拉近、「我」「不」的機率拉遠；為了不用人一直在旁邊，先用人類偏好訓練一個 reward model 代替人打分（若改用 DPO，則直接拿「玉山 > 我不知道」這組偏好對訓練，不需 reward model）。

對照 MyGO 實驗：預訓練資料若只寫一次「千早愛音是 MyGO!!!!! 的節奏吉他手」，SFT 教了一半人物的問答後，另一半人物的問題正確率 0%；把每個人物的介紹改寫成多種版本再預訓練，正確率升到 96%——知識要反覆、多角度地講，模型才能靈活取用。
